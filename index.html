GreenRead Pro
グリーンリード プロ - ゴルフグリーン傾斜測定アプリ

GreenRead Pro サポートページ

GreenRead Pro（グリーンリード プロ）は、iPhone / iPad の LiDAR スキャナとカメラを使って ゴルフグリーン上の傾斜を計測し、パッティングのライン読みを支援する計測補助アプリです。 実際のボールとピン（旗）の位置を画面に合わせ、端末の傾きを水平に整えるだけで、 距離・高低差・ブレイク（曲がり）・傾斜方向・予想転がりラインを画面上に表示します。

📱 動作環境： LiDAR スキャナを搭載した端末が必要です（iPhone 12 Pro 以降、iPad Pro）。 LiDAR 非対応の端末では傾斜測定をご利用いただけません。

2. 傾斜測定の基本操作

主な操作は「ボール設置 → ピン設置 → 姿勢を整えて確定」の3ステップです。

Step 1：ボール設置

  1. 実際のボールとピン（旗）が画面に映るように端末を構えます。
  2. 画面を指で押さえると、指から少し離れた位置に拡大円が表示されます。
  3. 指をすべらせて、拡大円の中心の十字（＋）を実際のボールに合わせます。
  4. 指を離すと設置完了です。設定で「自動切替」が ON の場合は自動で「ピン設置」へ進みます。

Step 2：ピン設置

  1. 実際のボールとピン（旗）が画面に映るように端末を構えます。
  2. 画面を指で押さえ、拡大円の中心の十字（＋）を実際のピンに合わせます。
  3. 指を離すと設置完了です。測定値の表示に切り替わります。
💡 精度を上げるコツ： Y軸 0° 近傍・X軸 45° 近傍の姿勢で設置すると測定精度が上がります。 また、ボールとピン（旗）を画面中央の黄色い中間線の近くに設置すると精度が上がります。

Step 3：姿勢を整えて確定（ホールド）

ボールとピンの両方を設置すると、説明エリアが姿勢調整ガイドに切り替わります。

  1. X軸：端末を上下に倒して、左側の X 針を 0° 近傍（赤点滅）に合わせます。
  2. Y軸：端末を左右にひねって、下部の Y 針を 0° 近傍（赤点滅）に合わせます。
  3. 表示中の針がすべて 0° 近傍にそろうと、自動でホールドされます（Autoホールド ON 時）。

3. 計測モード

モード説明有効条件
Ball モードゴルフボールの落下地点をタップして設置します。常に有効
Pin モードピン（旗）の位置をタップして設置します。Ball 設置済み

Pin ボタンは Ball を設置するまで無効化（半透明）されています。

4. 測定値の見方

距離（Distance）

2点間の3D直線距離です。設定した距離単位（m / cm / yd、初期値は yd）で表示されます。 基点は Ball で、Ball から測定地点（Pin）までの距離を示します。

高低差

Ball→Pin の高低差（cm）です。＋ は Pin が高い（打ち上げ）、− は Pin が低い（打ち下ろし）を表します。

ブレイク

ボールが曲がる量（cm）と方向です。H は左へ、S は右へ曲がることを示します。

5. 画面上の表示要素

測定が確定しホールドされると、画面が止まり以下の表示が見えるようになります。

表示意味
青い点線ボールからピンへの直線（基準線）
赤い点線狙う方向（打ち出し方向＝狙い線）
青い曲線予想される転がりライン（パッティング軌道線）
白い矢印その場所の下り坂の向き（傾斜方向矢印）
下部の断面図ボールからピンまでの高低の変化

ラインエリア

Ball→Pin を中心軸とする矩形エリアです。幅や枠線（白い点線）、エリア外の半透明表示などを設定できます。

断面図

画面下部の横長バーで、Ball を左端、Pin を右端に配置し、高低差を中央基準線からの上下オフセットで表現します。 中間点の断面も表示され、タップすると最前面と背面を切り替えられます。

デバイス姿勢メーター

  • Xメーター（画面左側・大型）：端末の前後の傾き（上下に倒す向き）を示します。
  • Yメーター（画面下部・小型）：端末の左右の傾き（ひねる向き）を示します。
  • 針が 0° 近傍に入ると赤色（点滅設定 ON 時は点滅）になり、水平状態の目安になります。
  • 画面中央の細い黄色の十字線は X/Y 軸ガイド線です。交差点（画面中央）がメーターの原点です。

6. ホールド機能

測定中の画面を一時的に止めて、詳細を確認しやすくする機能です。

ホールド中の挙動

  • 画面はホールド時点の状態を維持します。
  • カメラ映像の更新、マーカー追跡、測定値更新、姿勢メーターの更新がすべて停止します。
  • 新しいタップによる計測は無効になります。
  • 姿勢メーターおよび関連情報（X/Y 軸傾斜・操作ガイド・ガイド線）は非表示になります。

手動ホールド

「ホールド」ボタンをタップするとホールドを開始します。ホールド中はボタン表記が「再測定」に変わり、 タップすると解除して全計測値をリセットします。

Autoホールド

設定の「Autoホールド」が ON（初期値）のとき、次の条件をすべて満たすと自動的にホールドします。

  1. Autoホールド設定が ON
  2. ボールとピンが設置済み
  3. 表示中の軸メーターの傾斜がすべて 0° 近傍範囲内

7. 設定

傾斜測定画面の表示や挙動をカスタマイズできます。

未購入時は「※」の項目が固定値となり変更できません（購入で解放されます）

7.1 測定

  • 距離単位：m / cm / yd（初期値：yd）
  • ※ 深度平均カーネル：LiDAR 深度を平均化する範囲（3×3 / 5×5 / 7×7）
  • ※ ブレイク中間計算点数：ボール〜ピン間を等分割してブレイクを計算する点数
  • ボール設置とピン設置の自動切替：ボール設置後に自動でピン設置モードへ切替
  • ※ 位置決め円の半径 / ※ 円内の拡大率：位置決め時の拡大円の設定
  • 左利きモード：計測点をタッチ点の右側に表示

7.2 グリーン速度

パッティング軌道線のブレイク配分に使うグリーンの速さ（高速 / 中 / 低速）を選択します。

7.3 表示・レイアウト

  • フォントサイズ：画面上の測定値やラベルの文字サイズ（小 / 中 / 大）
  • ゴルフボール / PinFlag：画像の表示サイズ・位置
  • ラインエリア：幅・枠線・エリア外の半透明表示・濃さ・矢印の付け方
  • 傾斜方向矢印：矢印の強度スケール
  • ライン色：基準線・狙い線などの色（プリセットから選択）

7.4 デバイス姿勢メーター

  • X / Y メーター表示：各メーターの表示・非表示
  • ※ Autoホールド：0° 近傍で自動ホールドするか
  • ※ 操作ガイド表示：端末の回し方を示すガイドの表示
  • ※ 0°近傍で点滅 / 点滅周期 / 点滅ON比率：点滅表示の設定
  • ※ 軸の反転・オフセット・表示倍率・0°近傍範囲：針表示の微調整

7.5 データの管理

  • 設定データを保存：すべての設定を1つの JSON ファイルに書き出します。
  • 保存した設定データを戻す：JSON ファイルから設定を復元します。
  • 別端末や再インストール後に同じ設定を復元できます。（未購入時は購入案内が表示されます）

7.6 デフォルト設定に戻す

画面最上部のボタンで、すべての設定をアプリの初期値にリセットできます（確認ダイアログが表示されます）。

8. 無料体験と購入

8.1 無料で試す

初回起動時のメッセージで「OK」を選ぶと、累積1時間まですべての機能を無料で体験できます。 「NG」を選んだ場合は、期間制限のない機能限定の体験版になります。

  • 全機能の体験時間が終了すると、自動的に機能限定の体験版へ移行します。
  • 機能限定の体験版は、購入後に全機能版となります。

8.2 全機能版の購入

購入（買い切り・非消耗型）により、以下が利用可能になります。

  • 設定の全項目を変更できます。
  • 設定のバックアップ（保存・復元）機能が使えます。
  • アプリ内のバナー広告が非表示になります。
  • 購入は一度きりで、Apple ID（アカウント）に永続的に紐付きます。

「購入をリストア」ボタンから、過去の購入を復元できます。

9. 広告について

  • 未購入の場合、各画面の上部にバナー広告が表示されます。
  • 広告の読み込みに失敗した場合は、自動的に再読み込みを試みます。
  • 全機能版を購入すると表示されなくなります。
🔒 プライバシーについて： 計測データ・設定内容はすべてお使いの端末内にのみ保存されます。 カメラや LiDAR で取得したデータは計測処理のみに利用され、外部サーバーへ送信されることはありません。

10. よくある質問（FAQ）

Q. 「非対応デバイス」と表示されます。

本アプリは LiDAR スキャナを搭載した端末（iPhone 12 Pro 以降、iPad Pro）が必要です。 非対応の端末では傾斜測定をご利用いただけません。

Q. 測定値に誤差があります。

傾斜計測は、LiDAR センサの性能、直射日光・芝の湿り・計測距離・デバイスの角度・手ブレなど、 さまざまな要因で誤差が生じることがあります。表示される値は「参考値」です。 端末を水平に保ち、ボールとピンを画面中央の近くに設置すると精度が上がります。

Q. Autoホールドされません。

設定の「Autoホールド」が ON になっているか、ボールとピンが両方設置済みかをご確認ください。 また、表示中の軸メーターの傾斜がすべて 0° 近傍範囲内に入る必要があります。 針が赤色（点滅）になったらその姿勢を保って静止してください。

Q. 設定項目が変更できません。

未購入の場合、「※」の付いた項目は固定値となり変更できません。 全機能版を購入すると、すべての設定項目が変更可能になります。

Q. ボールやピンの位置がずれます。

設置済みのボールは、端末を動かしても画面表示範囲内であれば実物の上に追従します。 端末の傾き（姿勢）は保ったまま、必要に応じて向きだけを調整してください。

Q. 機種変更時に設定を引き継ぎたいです。

設定画面の「データの管理」から設定データを JSON ファイルとして保存し、新しい端末で 「保存した設定データを戻す」から復元できます（全機能版でご利用いただけます）。

Q. 競技で使用できますか？

競技規則・ローカルルールにより、ラウンド中の電子機器利用が制限される場合があります。 公式競技での使用可否は、必ず事前にご確認ください。
